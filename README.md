 Simulador de Folha de Pagamento 2026

Projeto desenvolvido para calcular descontos de INSS e IRRF com base nas regras de 2026.


 Funcionalidades

- Cálculo automático de INSS (progressivo)
- Cálculo de IRRF
- Exibição do salário líquido
- Mensagem de isenção de imposto


Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

Como usar

1. Digite o salário bruto
2. Clique em "Calcular"
3. Veja os resultados na tela
